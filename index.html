HOW TO USE THIS TEMPLATE
  1. Define 2–3 concrete objectives per area (more than that dilutes learning).
  2. Score progress on each objective from 0 to 100 % and note the related weekly work.
  3. Choose ONE focus for the next block and review every 4–6 weeks using video and small-sided games.
